# Папка для шрифтов

Эта папка предназначена для хранения локальных шрифтов, если потребуется.

## Текущая реализация

В данный момент используется шрифт **Montserrat Extra Bold**, подключаемый через Google Fonts в `index.html`.

## Локальные шрифты (если нужно)

Если потребуется использовать локальные файлы шрифтов (например, кастомные версии или для работы оффлайн), разместите их здесь и подключите через CSS:

```css
@font-face {
  font-family: 'Montserrat';
  src: url('./fonts/Montserrat-ExtraBold.woff2') format('woff2'),
       url('./fonts/Montserrat-ExtraBold.woff') format('woff');
  font-weight: 800;
  font-style: normal;
  font-display: swap;
}
```

## Форматы шрифтов

Рекомендуемые форматы:
- `.woff2` - лучшая компрессия (приоритет)
- `.woff` - хорошая совместимость (fallback)
- `.ttf` - универсальный формат

## Использование

Генератор текста для выигрышей (`MiniWinText.js`) автоматически использует подключенный шрифт Montserrat.
