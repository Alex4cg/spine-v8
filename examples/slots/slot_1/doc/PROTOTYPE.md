# Прототип слота - Общая архитектура

## Описание

Прототип слота представляет собой игровой автомат на базе PixiJS и Spine, реализующий классический слот с барабанами, выигрышными линиями, анимациями и системой монеток с перелетами к поезду.

## Технологический стек

- **PixiJS** - Графический движок для рендеринга 2D графики
- **Spine** - Система скелетной анимации для сложных анимаций
- **JavaScript (ES6+)** - Основной язык программирования
- **HTML5** - Разметка и точка входа

## Архитектура

### Основной класс: SlotMachine

`SlotMachine` является центральным оркестратором всех систем игры. Он управляет жизненным циклом игры, координацией между компонентами и обработкой событий.

**Основные обязанности:**
- Инициализация всех систем
- Управление состоянием игры (спин, остановка)
- Координация между барабанами, эффектами и анимациями
- Обработка сценариев игры
- Управление контейнерами и z-индексами

### Структура контейнеров (Z-Index)

Игра использует систему слоев для правильного отображения элементов:

```
Z-Index 300: Кнопка спин (SpinButton)
Z-Index 250: Логотип (Spine)
Z-Index 200: Эффекты поверх символов (WinFrameAnimation)
Z-Index 150: Spine анимации (монетки, индикаторы)
Z-Index 105: Монетки (CoinManager)
Z-Index 104: Индикаторы монеток
Z-Index 100: Барабаны (SlotReel)
Z-Index 99:  Винлайны (WinLineManager)
Z-Index 95:  Частицы монет (ParticleSystem - coinLayer)
Z-Index 90:  Поезд (TrainManager)
Z-Index 85:  Частицы дыма (ParticleSystem - particleLayer)
Z-Index 50:  Фоновые элементы
```

## Основные компоненты

### 1. Барабаны (SlotReel)

**Файл:** `SlotReel.js`

Управляет одним барабаном с символами.

**Функциональность:**
- Отображение символов в виде спрайтов
- Трехфазная анимация спина (разгон, линейное движение, торможение)
- Остановка на заданной позиции
- Подмена спрайтовых монет на Spine анимации
- Маскирование для создания эффекта прокрутки

**Ключевые методы:**
- `spin()` - Запуск спина
- `stopAtPosition()` - Остановка на конкретной позиции
- `setCoinSymbolVisible()` - Скрытие/показ спрайтовой монеты

### 2. Менеджер монеток (CoinManager)

**Файл:** `CoinManager.js`

Управляет Spine анимациями монеток на игровом поле.

**Функциональность:**
- Отображение монеток на позициях матрицы 3x3
- Последовательность анимаций: `shot` → `idle`
- Событие `start_flight` для запуска перелета
- Интеграция с CollectEffect для перелетов
- Скрытие спрайтовых монет при показе Spine монет

**Ключевые методы:**
- `showCoin(positionIndex, value)` - Показать монетку с значением
- `hideCoin(positionIndex)` - Скрыть монетку
- `playCoinAnimationSequence()` - Проиграть последовательность анимаций
- `hideAllCoins()` - Скрыть все монетки

### 3. Система перелетов (CollectEffect)

**Файл:** `CollectEffect.js`

Управляет анимацией перелета монет от поля к поезду.

**Функциональность:**
- Множественные одновременные перелеты
- Дугообразная траектория через кривую Безье
- Динамическое определение направления отклонения
- Интеграция с поездом и частицами через callback

**Ключевые методы:**
- `playHitCoin(startPosition)` - Запустить перелет монеты
- `setControlPointsForInstance()` - Установить контрольные точки траектории
- `setOnHitCallback()` - Установить callback при достижении цели

### 4. Менеджер поезда (TrainManager)

**Файл:** `TrainManager.js`

Управляет Spine анимацией поезда.

**Функциональность:**
- Постоянные зацикленные анимации (idle, piles_of_gold, bg_speed_effect)
- Разовые анимации при спине (blick_add, steam_1, steam_2)
- Реакция на прилет монет (анимация `active`)
- Динамическое увеличение масштаба (0.3% за прилет, максимум 5%)

**Ключевые методы:**
- `init()` - Инициализация и загрузка
- `playSpinAnimation()` - Анимация при спине
- `playActiveAnimation()` - Реакция на прилет монеты
- `getPosition()` - Получить позицию поезда

### 5. Система частиц (ParticleSystem)

**Файл:** `ParticleSystem.js`

Управляет эмиттерами частиц вокруг поезда.

**Функциональность:**
- Эмиттер дыма за поездом
- Эмиттеры золотых монет перед поездом
- Реакция на прилет монет (всплеск частиц)
- Привязка к костям поезда для динамического позиционирования

**Ключевые методы:**
- `init(trainSpine)` - Инициализация системы
- `triggerHitBurst()` - Создать всплеск частиц при прилете

### 6. Менеджер выигрышных линий (WinLineManager)

**Файл:** `WinLineManager.js`

Управляет отображением выигрышных линий.

**Функциональность:**
- Одновременный или последовательный показ линий
- Интеграция с текстами выигрышей
- Синхронизация с winframes

### 7. Анимация выигрышных рамок (WinFrameAnimation)

**Файл:** `WinFrameAnimation.js`

Управляет анимацией рамок вокруг выигрышных символов.

**Функциональность:**
- Спрайтовый пул для оптимизации
- Статическое позиционирование относительно игрового поля
- Анимация из атласа (60 кадров)

### 8. Генератор текста выигрышей (MiniWinText)

**Файл:** `MiniWinText.js`

Создает стилизованный золотой 3D текст для отображения выигрышей.

**Функциональность:**
- Градиенты и обводки
- Кеширование текстур
- Анимация появления

### 9. Сценарии игры (GameScenarios)

**Файл:** `GameScenarios.js`

Управляет предопределенными результатами спинов для тестирования.

**Функциональность:**
- Загрузка сценариев из JSON
- Применение матриц результатов к спинам
- Создание выигрышных комбинаций

### 10. Отладчик позиций (DebugPositionEditor)

**Файл:** `DebugPositionEditor.js`

Визуальный инструмент для настройки позиций элементов.

**Функциональность:**
- Настройка позиции, масштаба и zIndex
- Сохранение в localStorage
- Управление всеми элементами игры

## Поток игры

### Инициализация

1. Создание PixiJS Application
2. Загрузка текстур символов
3. Инициализация SlotMachine
4. Загрузка всех систем:
   - Барабаны (SlotReel)
   - Менеджер монеток (CoinManager)
   - Система перелетов (CollectEffect)
   - Менеджер поезда (TrainManager)
   - Система частиц (ParticleSystem)
   - Винлайны (WinLineManager)
   - Выигрышные рамки (WinFrameAnimation)
5. Загрузка сценариев (если включены)
6. Настройка отладчика (если включен)

### Процесс спина

1. **Начало спина:**
   - Кнопка спин становится неактивной
   - Скрываются все монетки (`coinManager.hideAllCoins()`)
   - Запускается анимация поезда (`trainManager.playSpinAnimation()`)
   - Запускается спин всех барабанов (`reel.spin()`)

2. **Во время спина:**
   - Барабаны прокручиваются с трехфазной анимацией
   - Частицы дыма и монет продолжают работать

3. **Остановка барабанов:**
   - Барабаны останавливаются последовательно с задержкой
   - Применяется матрица результатов из сценария

4. **После остановки:**
   - Проверка выигрышных комбинаций
   - Отображение монеток (`coinManager.showCoin()`)
   - Запуск анимации монеток (`shot` → `idle`)
   - При событии `start_flight`:
     - Запуск перелета (`collectEffect.playHitCoin()`)
     - При достижении поезда (`collect_effect_hit`):
       - Реакция поезда (`trainManager.playActiveAnimation()`)
       - Всплеск частиц (`particleSystem.triggerHitBurst()`)
   - Отображение выигрышных линий и рамок
   - Кнопка спин становится активной

## Конфигурация

Основной файл конфигурации: `config.js`

**Ключевые параметры:**
- `resolution` - Разрешение экрана (1920x1080)
- `reels` - Количество барабанов и символов
- `gameMode` - Режим игры ('classic' или 'holdnwin')
- `spinDuration` - Длительность спина
- `reelAnimation` - Параметры анимации барабанов
- `scenarios` - Настройки сценариев
- `spine` - Конфигурация Spine анимаций
- `debug` - Настройки отладки

## События и интеграция

### События Spine анимаций

**Монетки:**
- `start_flight` - Запуск перелета монеты

**Collect Effect:**
- `collect_effect_hit` - Достижение монетой поезда

### Callback система

**CollectEffect → TrainManager:**
```javascript
collectEffect.setOnHitCallback(() => {
  trainManager.playActiveAnimation();
});
```

**CollectEffect → ParticleSystem:**
```javascript
collectEffect.setOnHitCallback(() => {
  particleSystem.triggerHitBurst();
});
```

## Особенности реализации

### Множественные перелеты

Каждая монетка создает свой экземпляр Spine анимации для перелета, что позволяет одновременно отображать несколько перелетов.

### Динамическое масштабирование поезда

Поезд увеличивается на 0.3% за каждый прилет монеты, максимум до 5%. Это создает визуальный эффект "наполнения" поезда.

### Трехфазная анимация барабанов

1. **Разгон** - Ускорение до линейной скорости
2. **Линейное движение** - Постоянная скорость
3. **Торможение** - Замедление до остановки

### Привязка частиц к костям

Частицы привязаны к костям поезда (`place_holder_emitter_1`, `place_holder_emitter_gold_1`, `place_holder_emitter_gold_2`), что позволяет им следовать за анимацией поезда.

## Расширяемость

Прототип спроектирован с учетом расширяемости:

- **Новые режимы игры:** Добавление через `gameMode` в конфигурации
- **Новые Spine анимации:** Через систему `SpineAnimation`
- **Новые эффекты:** Через систему контейнеров и z-index
- **Новые типы частиц:** Через расширение `ParticleSystem`
- **Новые сценарии:** Через систему `GameScenarios`
