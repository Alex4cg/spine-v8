# Работа со сценариями игры

## Обзор

Система сценариев позволяет предопределить результаты каждого спина, создавая контролируемую последовательность выигрышных комбинаций. Это используется для тестирования, демонстрации и создания предсказуемых игровых сессий.

## Структура сценария

### Формат файла

Сценарий хранится в JSON-файле (по умолчанию `./matrix/scenario.json`) и представляет собой массив объектов для каждого спина.

### Структура матрицы

Каждая матрица в сценарии имеет структуру: `matrix[position][reelIndex]`

```json
{
  "matrix": [
    [верхний_рил0, верхний_рил1, верхний_рил2],
    [средний_рил0, средний_рил1, средний_рил2],
    [нижний_рил0, нижний_рил1, нижний_рил2]
  ],
  "coinValues": [[...], [...], [...]],
  "collectorValue": 0,
  "winLines": [],
  "events": []
}
```

**Важно:**
- Первый уровень массива: позиция символа (0 = верхний, 1 = средний, 2 = нижний)
- Второй уровень массива: индекс рила (0 = рил 0, 1 = рил 1 средний, 2 = рил 2)
- Значение: индекс текстуры символа (0 до `количество_символов - 1`)
  - 8 = монетка
  - 10 = коллектор

## Правила размещения символов

### Правила размещения монеток (индекс 8)

1. **Монетка НЕ может быть на среднем риле (reelIndex = 1)**
   - Монетка может быть только на рилах 0 и 2 (reelIndex = 0 или 2)
   - Монетка может быть в любой позиции (0, 1, 2) на разрешенных рилах

2. **Если монетка есть в матрице, обязательно заполнить coinValues**
   - Формат: `coinValues[position][reelIndex]`
   - Если `matrix[position][reelIndex] == 8`, то `coinValues[position][reelIndex]` должно быть **целым числом** (не дробным)
   - Если `matrix[position][reelIndex] != 8`, то `coinValues[position][reelIndex] = null`

### Правила размещения коллекторов (индекс 10)

1. **Коллектор может быть ТОЛЬКО на среднем риле (reelIndex = 1)**
   - Коллектор НЕ может быть на рилах 0 и 2
   - Коллектор может быть в любой позиции (0, 1, 2) на среднем риле

2. **Если коллектор есть в матрице:**
   - Обязательно добавить поле `collectorValue` (число)
   - `collectorValue` = сумма всех значений из `coinValues`, где есть монетки
   - Формула: `collectorValue = sum(coinValues[position][reelIndex] для всех position, reelIndex, где matrix[position][reelIndex] == 8)`

### Пример расчета collectorValue

Если матрица:
```json
{
  "matrix": [[8, 3, 8], [3, 10, 7], [6, 2, 4]],
  "coinValues": [[2.5, null, 3.0], [null, null, null], [null, null, null]]
}
```

Расчет:
- Монетки: позиция 0 рил 0 (2.5) + позиция 0 рил 2 (3.0)
- `collectorValue = 2.5 + 3.0 = 5.5`

## Правила событий

### Событие "coin_collector"

**Условие:** В матрице есть коллектор (10)

**Правила:**
- Коллектор должен быть на среднем риле (reelIndex = 1)
- Если есть коллектор, обязательно добавить событие `"coin_collector"` в массив `events`
- Обязательно указать `collectorValue` (сумма всех монеток)

**Пример:**
```json
{
  "matrix": [[8, 3, 6], [3, 10, 8], [1, 4, 7]],
  "coinValues": [[3, null, null], [null, null, 5], [null, null, null]],
  "collectorValue": 8,
  "events": ["coin_collector"]
}
```

### Событие "intriga"

**Условие:** На рилах 0 и 1 одновременно есть монетки (8) или коллекторы (10)

**Правила:**
- Проверка рила 0 (reelIndex = 0): есть монетка или коллектор в любой позиции
- Проверка рила 1 (reelIndex = 1): есть монетка или коллектор в любой позиции
- **Важно:** Монетка на риле 1 невозможна по правилам, поэтому на риле 1 должен быть коллектор
- Если условие выполнено, добавить событие `"intriga"` в массив `events`

**Пример:**
```json
{
  "matrix": [[8, 3, 6], [3, 10, 4], [1, 4, 7]],
  "coinValues": [[3, null, null], [null, null, null], [null, null, null]],
  "collectorValue": 3,
  "events": ["coin_collector", "intriga"]
}
```
- Рил 0: есть монетка (8) на позиции 0 ✅
- Рил 1: есть коллектор (10) на позиции 1 ✅
- Событие "intriga" добавлено ✅

## Алгоритм генерации спина для ИИ

### Шаг 1: Создание базовой матрицы
```json
{
  "matrix": [
    [символ, символ, символ],
    [символ, символ, символ],
    [символ, символ, символ]
  ]
}
```

### Шаг 2: Добавление монеток (если нужно)
- Добавить монетки (8) только на рилы 0 и 2
- НЕ добавлять монетки на средний рил (reelIndex = 1)

### Шаг 3: Добавление коллектора (если нужно)
- Добавить коллектор (10) только на средний рил (reelIndex = 1)
- НЕ добавлять коллектор на рилы 0 и 2

### Шаг 4: Заполнение coinValues
- Для каждой монетки (8) в матрице указать значение в `coinValues[position][reelIndex]`
- Для всех остальных позиций указать `null`

### Шаг 5: Расчет collectorValue (если есть коллектор)
- Найти все монетки в матрице
- Суммировать их значения из `coinValues`
- Установить `collectorValue = сумма`

### Шаг 6: Определение событий
- **"coin_collector"**: добавить, если есть коллектор (10) в матрице
- **"intriga"**: добавить, если на рилах 0 и 1 одновременно есть монетки или коллекторы

### Шаг 7: Заполнение winLines
- Определить выигрышные линии (если есть)
- Массив индексов линий: `[1, 2, 3, ...]` или `[]` если нет выигрышей

## Полный пример спина

```json
{
  "matrix": [[8, 3, 6], [3, 10, 8], [1, 4, 7]],
  "coinValues": [[3, null, null], [null, null, 5], [null, null, null]],
  "collectorValue": 8,
  "winLines": [],
  "events": ["coin_collector", "intriga"]
}
```

**Проверка правил:**
- ✅ Монетки только на рилах 0 и 2 (не на среднем)
- ✅ Коллектор только на среднем риле (reelIndex = 1)
- ✅ coinValues заполнен для всех монеток
- ✅ collectorValue = 3 + 5 = 8 (сумма монеток)
- ✅ Событие "coin_collector" (есть коллектор)
- ✅ Событие "intriga" (монетка на риле 0 + коллектор на риле 1)

## Конфигурация

### Включение/выключение сценариев

В `config.js`:

```javascript
scenarios: {
  enabled: true,  // включить систему сценариев
  scenarioPath: './matrix/scenario.json'  // путь к файлу сценария
}
```

### Валидация

Система автоматически валидирует сценарий при загрузке:
- Проверяет структуру массива
- Проверяет количество рилов (должно совпадать с `config.reels.count`)
- Проверяет количество символов на рил (должно совпадать с `config.reels.symbolsPerReel`)
- Проверяет диапазон индексов текстур (0 до `количество_символов - 1`)

## Как работает система

### Загрузка сценария

1. При инициализации `SlotMachine` вызывается `scenarios.loadScenario()`
2. Файл загружается через `fetch()`
3. Выполняется валидация структуры и данных
4. Сценарий сохраняется в памяти, индекс текущего спина = 0

### Применение матрицы при спине

1. При каждом спине вызывается `scenarios.getCurrentMatrix()`
2. Возвращается матрица для текущего спина (или `null` если сценарий закончился)
3. Матрица передается в каждый рил через `reel.startSpin(resultMatrix)`
4. После спина вызывается `scenarios.nextSpin()` для перехода к следующему спину

### Логика присвоения текстур

В `SlotReel.startSpin(resultMatrix)`:

1. **Копирование текстур** (как обычно): текстуры из видимых символов копируются в целевые позиции
2. **Мгновенное смещение вверх**: весь массив смещается вверх
3. **Пауза 0.3 секунды**
4. **Применение матрицы** (если передана):
   - Текстуры из матрицы присваиваются символам, которые станут видимыми после анимации
   - Структура: `resultMatrix[позиция][рил]`
   - Присвоение: `finalVisibleIndices[2]` (верхний) = `resultMatrix[0][reelIndex]`
   - Присвоение: `finalVisibleIndices[1]` (средний) = `resultMatrix[1][reelIndex]`
   - Присвоение: `finalVisibleIndices[0]` (нижний) = `resultMatrix[2][reelIndex]`
5. **Рандомизация остальных**: все символы кроме защищенных (5 для копирования + 3 видимых) рандомизируются
6. **Анимация вниз**: плавное движение до финальной позиции

### Защита символов

При использовании сценария защищены от рандомизации:
- 5 символов для копирования текстур (предотвращают визуальные артефакты)
- 3 видимых символа (которые получают текстуры из матрицы)

## Создание сценариев

### Рекомендации

1. **Горизонтальные линии**: создавайте линии одинаковых символов для тестирования winframe анимации
   ```json
   {
     "matrix": [
       [1, 1, 1],  // верхняя линия
       [2, 3, 4],  // случайные
       [5, 5, 5]   // нижняя линия
     ],
     "winLines": [1, 3]
   }
   ```

2. **Последовательность**: планируйте последовательность спинов для создания интересных паттернов
3. **Длина**: стандартный сценарий содержит 30 спинов (соответствует `config.maxSpins`)

### Примеры паттернов

**Все случайные:**
```json
{
  "matrix": [
    [0, 3, 6],
    [1, 4, 7],
    [2, 5, 8]
  ],
  "winLines": []
}
```

**Одна горизонтальная линия:**
```json
{
  "matrix": [
    [1, 1, 1],  // линия на верхней позиции
    [2, 3, 4],
    [5, 6, 7]
  ],
  "winLines": [1]
}
```

**Спин с монетками и коллектором:**
```json
{
  "matrix": [[8, 3, 8], [3, 10, 7], [6, 2, 4]],
  "coinValues": [[2.5, null, 3.0], [null, null, null], [null, null, null]],
  "collectorValue": 5.5,
  "winLines": [],
  "events": ["coin_collector", "intriga"]
}
```

## API класса GameScenarios

### Методы

- `async loadScenario(scenarioPath)` - загружает сценарий из файла
- `getCurrentMatrix()` - возвращает матрицу для текущего спина (или `null`)
- `getCurrentEvents()` - возвращает события для текущего спина
- `getCurrentWinLines()` - возвращает выигрышные линии для текущего спина
- `nextSpin()` - переходит к следующему спину в сценарии
- `reset()` - сбрасывает индекс на начало сценария
- `hasMoreSpins()` - проверяет, есть ли еще спины в сценарии

## Интеграция с winframe анимацией

Система winframe автоматически определяет горизонтальные линии одинаковых символов и подсвечивает их анимацией. Это работает независимо от того, использовался ли сценарий или нет - проверка выполняется по фактическим видимым символам после остановки всех рилов.

## Отладка

### Логирование

Система выводит в консоль:
- `Scenario loaded: X spins` - при успешной загрузке
- `Spin X: Using scenario matrix` - при использовании матрицы
- `Reel X: Applied scenario - [top, middle, bottom]` - при присвоении текстур
- Ошибки валидации при загрузке

### Проверка работы

1. Убедитесь что `scenarios.enabled = true` в конфиге
2. Проверьте путь к файлу сценария
3. Проверьте структуру JSON (валидность, количество рилов, символов)
4. Проверьте диапазон индексов текстур (0 до `количество_символов - 1`)
5. Проверьте соблюдение правил размещения монеток и коллекторов
6. Проверьте правильность расчета `collectorValue`
7. Проверьте корректность событий

## Чек-лист для создания спина

- [ ] Матрица создана с правильной структурой `[position][reelIndex]`
- [ ] Монетки (8) размещены только на рилах 0 и 2 (не на среднем риле)
- [ ] Коллектор (10) размещен только на среднем риле (reelIndex = 1)
- [ ] `coinValues` заполнен для всех монеток (числа) и `null` для остальных
- [ ] Если есть коллектор, указан `collectorValue` (сумма всех монеток)
- [ ] Если есть коллектор, добавлено событие `"coin_collector"`
- [ ] Если на рилах 0 и 1 есть монетки/коллекторы, добавлено событие `"intriga"`
- [ ] `winLines` заполнен (массив индексов линий или пустой массив)
