# Логика спина для слот-машины

## Структура массива символов

- Массив содержит `totalSymbols` символов (по умолчанию 20, минимум `visibleSymbols + 5`)
- **Порядок в массиве**: индекс 0 = нижний, индекс `totalSymbols - 1` = верхний
- **Индексы жестко привязаны**: символ с индексом `i` всегда имеет индекс `i`
- **Порядок отображения**: верхний > ... > средний > нижний
- Индексы и порядок в массиве **никогда не меняются** - меняются только позиции Y и текстуры

## Конфигурируемые параметры

- `totalSymbols`: общее количество символов в риле (минимум `visibleSymbols + 5`)
- `spinOffset`: количество символов, на которое смещается рил (от 3 до `totalSymbols - visibleSymbols`)
- `visibleSymbols`: количество видимых символов (обычно 3)
- `symbolSpacing`: расстояние между символами (равно `symbolSize.height`)

## Стартовая позиция (при загрузке страницы)

- **Видимы символы с индексами** `visibleStartIndex`, `visibleStartIndex + 1`, `visibleStartIndex + 2`
- `visibleStartIndex = totalSymbols - visibleSymbols - 1`
- Для `totalSymbols = 20` и `visibleSymbols = 3`: видимы индексы 16, 17, 18
- Позиции символов относительно контейнера:
  - `symbols[totalSymbols - 1]`: Y = -symbolSpacing (выше видимой области)
  - `symbols[visibleStartIndex + 2]`: Y = 0 (верхний видимый)
  - `symbols[visibleStartIndex + 1]`: Y = symbolSpacing (средний видимый)
  - `symbols[visibleStartIndex]`: Y = 2 * symbolSpacing (нижний видимый)
- Символы с индексами 0 до `visibleStartIndex - 1` находятся ниже видимой области

## Логика при нажатии кнопки SPIN

### Шаг 1: Копирование текстур (расширенное)
- Копируются текстуры из 5 символов (1 выше видимых + 3 видимых + 1 ниже видимых)
- Это предотвращает визуальные артефакты от графики, выходящей за границы символов
- Источники: `visibleStartIndex - 1`, `visibleStartIndex`, `visibleStartIndex + 1`, `visibleStartIndex + 2`, `visibleStartIndex + 3`
- Цели: `sourceIndex - spinOffset` для каждого источника
- Индексы символов **не меняются** - меняются только текстуры

### Шаг 2: Мгновенное смещение вверх
- Все символы мгновенно смещаются **вверх** на `spinOffset * symbolSpacing` пикселей
- **Смещается весь массив, не меняя его порядок и структуру**
- После смещения видимы символы с индексами `targetIndex1`, `targetIndex2`, `targetIndex3` (куда скопировались текстуры)
- **Микропауза 0.3 секунды** - чтобы видеть что текстуры присвоены верно

### Шаг 3: Применение сценария (если есть) и рандомизация
- Если передан `resultMatrix` из сценария:
  - Текстуры из матрицы присваиваются символам, которые станут видимыми после анимации
  - Структура матрицы: `resultMatrix[позиция][рил]` (0=верхний, 1=средний, 2=нижний)
  - Присвоение: `finalVisibleIndices[2]` (верхний) = `resultMatrix[0][reelIndex]`
  - Присвоение: `finalVisibleIndices[1]` (средний) = `resultMatrix[1][reelIndex]`
  - Присвоение: `finalVisibleIndices[0]` (нижний) = `resultMatrix[2][reelIndex]`
- Рандомизация: всем символам **кроме защищенных** присваиваются случайные текстуры
- Защищенные индексы: 5 для копирования + 3 видимых (если использовался сценарий)
- Индексы символов **не меняются**

### Шаг 4: Анимация смещения вниз (трехфазная)
- Все символы плавно двигаются **вниз** на `spinOffset * symbolSpacing` пикселей
- **Трехфазная анимация:**
  1. **Разгон** (0.3 сек): плавное ускорение на расстоянии 1 символа (`easeInCubic`)
  2. **Линейное движение**: постоянная скорость `linearSpeed` символов/сек для оставшегося расстояния
  3. **Торможение** (0.3 сек): плавное замедление с отскоком на расстоянии 1 символа (`easeOutBack`)
- Параметры из конфига: `accelerationTime`, `decelerationTime`, `linearSpeed`
- Анимация останавливается когда достигнуто целевое расстояние
- Порядок символов в массиве **не меняется** - меняются только позиции Y

### Шаг 5: Остановка
- После завершения анимации видимы символы с индексами `visibleStartIndex`, `visibleStartIndex + 1`, `visibleStartIndex + 2`
- Позиции вернулись к стартовым (как при загрузке страницы)
- Текстуры остаются такими, какими были во время движения (не меняются)
- Вызывается `onSpinComplete` для уведомления о завершении спина

## Важно

- **Порядок в массиве**: индекс 0 = нижний, индекс `totalSymbols - 1` = верхний (никогда не меняется)
- **Индексы символов**: жестко привязаны, никогда не меняются
- **Меняются только**: позиции Y (при анимации) и текстуры (при копировании, рандомизации и применении сценария)
- Каждый спин работает одинаково (нет различий между первым и последующими)
- Стартовая позиция всегда одинакова: видимы `visibleStartIndex`, `visibleStartIndex + 1`, `visibleStartIndex + 2`
- После каждого спина возвращаемся к стартовой позиции
- Расширенное копирование (5 символов) предотвращает визуальные артефакты
- Трехфазная анимация обеспечивает плавный старт и эффектную остановку с отскоком
