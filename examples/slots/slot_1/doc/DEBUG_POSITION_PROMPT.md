# Отладчик позиции и трансформаций (Position Debugger)

## Обзор

Отладчик позиции позволяет визуально настраивать позицию, масштаб и порядок отрисовки (zIndex) элементов сцены в реальном времени. Это незаменимый инструмент для точной настройки расположения элементов интерфейса, Spine анимаций и фоновых элементов.

## Включение/выключение

### В конфигурации

В `config.js`:

```javascript
debug: {
  positionEditor: true  // включить отладчик позиции
}
```

### Интерфейс

- **Кнопка "🔧 Debug"** всегда видна в правом верхнем углу экрана
- При клике открывается/закрывается панель отладки
- Панель появляется в правом верхнем углу поверх всего контента

## Доступные элементы

### Контейнеры

- **Reels Container (with Frame & Mask)** - контейнер с барабанами, рамой и маской (трансформируются вместе)
- **Effects Container** - контейнер для эффектов (winframe анимации и т.д.)

### Spine анимации

- **Train Spine Container** - контейнер поезда (Spine анимация)
- **Logo Spine Container** - контейнер логотипа (Spine анимация)

### Фоновые элементы

- **BG: bg_desktop_reg** - фоновое изображение рабочего стола
- **BG: field** - поле игры
- **BG: jp** - элемент JP (Jackpot)
- **BG: top** - верхний элемент фона

## Управление параметрами

### X Position (Позиция по X)

- **Диапазон**: -2000 до 2000 пикселей
- **Шаг**: 1 пиксель
- **Стрелки**: ◄ ► для точной настройки с шагом 1
- Управляет горизонтальной позицией элемента

### Y Position (Позиция по Y)

- **Диапазон**: -2000 до 2000 пикселей
- **Шаг**: 1 пиксель
- **Стрелки**: ◄ ► для точной настройки с шагом 1
- Управляет вертикальной позицией элемента

### Scale (Масштаб)

- **Диапазон**: 0.1 до 5.0
- **Шаг**: 0.01
- **Стрелки**: ◄ ► для точной настройки с шагом 0.01
- **Пропорциональное масштабирование**: изменяет scale.x и scale.y одновременно
- Управляет размером элемента

### Z Index (Порядок отрисовки)

- **Диапазон**: 0 до 1000
- **Шаг**: 1
- **Стрелки**: ◄ ► для точной настройки с шагом 1
- Управляет порядком отрисовки элементов (чем больше значение, тем выше элемент)
- Для элементов на `stage` работает глобальная сортировка

## Кнопки управления

### Reset (Сброс)

- Возвращает выбранный элемент к значениям по умолчанию
- Применяется мгновенно
- Не сохраняется автоматически

### Save (Сохранить)

- Сохраняет текущие значения элемента в `localStorage`
- Значения автоматически загружаются при следующем запуске
- Показывает уведомление "✓ Saved!" на 1 секунду

## Сохранение и загрузка

### Автоматическое сохранение

- Все изменения применяются в реальном времени
- Для сохранения между сессиями нужно нажать кнопку "Save"
- Данные хранятся в `localStorage` браузера

### Формат сохранения

```javascript
{
  x: 960,           // позиция X
  y: 540,           // позиция Y
  scale: 1.0,       // масштаб (пропорциональный)
  zIndex: 150       // порядок отрисовки
}
```

**Ключ в localStorage**: `debug_<имя_элемента>`

Примеры:
- `debug_reelsContainer`
- `debug_train`
- `debug_bg_bg_desktop_reg`

### Автоматическая загрузка

При запуске приложения:
1. Отладчик загружает сохраненные значения из `localStorage`
2. Применяет их к соответствующим элементам
3. Если сохраненных значений нет, используются значения по умолчанию

## Особенности работы

### Reels Container

- При трансформации `reelsContainer` автоматически трансформируются:
  - `gameMask` (маска скрывающая символы вне игровой зоны)
  - `gameFrame` (рама игрового поля, скрыта по умолчанию)
- Это обеспечивает синхронное движение всех элементов игрового поля

### Spine анимации

- Каждая Spine анимация находится в своем контейнере на `stage`
- Трансформации применяются к контейнеру, а не к самому спайну
- zIndex работает глобально на уровне всей сцены
- События Spine работают независимо от контейнера

### Фоновые элементы

- Каждый фоновый элемент (спрайт) находится напрямую на `stage`
- zIndex работает глобально
- Можно позиционировать каждый элемент независимо

## Значения по умолчанию

### Контейнеры

- **Reels Container**: `{ x: 0, y: 0, scale: 1, zIndex: 100 }`
- **Effects Container**: `{ x: 0, y: 0, scale: 1, zIndex: 200 }`

### Spine анимации

- **Train Container**: `{ x: 960, y: 880, scale: 1, zIndex: 150 }`
- **Logo Container**: `{ x: 960, y: 540, scale: 1, zIndex: 250 }`

### Фоновые элементы

- **bg_desktop_reg**: `{ x: 960, y: 540, scale: 1, zIndex: 10 }`
- **field**: `{ x: 960, y: 540, scale: 1, zIndex: 20 }`
- **jp**: `{ x: 960, y: 540, scale: 1, zIndex: 30 }`
- **top**: `{ x: 960, y: 540, scale: 1, zIndex: 40 }`

## Структура zIndex (по умолчанию)

```
10-40    Фоновые элементы (bg_desktop_reg, field, jp, top)
100      Reels Container (барабаны)
150      Train Container
200      Effects Container (winframe анимации)
250      Logo Container
```

## Добавление новых элементов

Для добавления нового элемента в отладчик нужно обновить метод `registerElements()` в `DebugPositionEditor.js`:

```javascript
'myElement': {
  name: 'My Element Name',
  getElement: () => this.slotMachine.myElement,
  defaultValues: { x: 960, y: 540, scale: 1, zIndex: 100 }
}
```

## Отладка

### Логирование

Отладчик выводит в консоль:
- `DebugPositionEditor: Initializing...` - при инициализации
- `Selected element <name>, zIndex: <value>` - при выборе элемента
- `Setting zIndex for <name> to <value>` - при изменении zIndex
- `Saved values for <name>: <values>` - при сохранении
- `Loaded saved values for <name>: <values>` - при загрузке

### Проверка работы

1. Убедитесь что `debug.positionEditor: true` в конфиге
2. Проверьте что кнопка "🔧 Debug" видна в правом верхнем углу
3. Откройте панель и проверьте список элементов
4. Выберите элемент и попробуйте изменить параметры
5. Проверьте что изменения применяются в реальном времени
6. Сохраните значения и обновите страницу - они должны загрузиться

## Ограничения

- Максимальное количество элементов ограничено только производительностью браузера
- Значения сохраняются только в текущем браузере (localStorage)
- При очистке данных браузера все сохраненные значения будут потеряны
- zIndex работает только если у родительского контейнера `sortableChildren = true`

## Рекомендации

1. **Используйте стрелки** для точной настройки позиции
2. **Сохраняйте часто** - особенно после нахождения правильных позиций
3. **Проверяйте на разных разрешениях** - позиции могут отличаться
4. **Используйте zIndex** для правильного порядка отрисовки слоев
5. **Сбрасывайте при необходимости** - кнопка Reset вернет значения по умолчанию
