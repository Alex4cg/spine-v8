## Быстрый старт

### Настройка конфигурации

Основной файл конфигурации: `config.js`

```javascript
export const SLOT_CONFIG = {
  reels: { count: 3, symbolsPerReel: 3 },
  symbolSize: { width: 302, height: 166 },
  scenarios: { enabled: true },
  spine: { train: { enabled: true } },
  debug: { positionEditor: true }
};
```

## Основные концепции

### Символы и текстуры

- Символы используют текстуры из папки `sym_st/`
- Каждый символ имеет фиксированный размер (`symbolSize`)
- Текстуры загружаются автоматически при инициализации

### Барабаны (Reels)

- Каждый барабан содержит массив символов
- Символы имеют фиксированные индексы (не меняются)
- При спине меняются только позиции Y и текстуры

### Сценарии

- Предопределенные результаты спинов
- Матрица 3x3 для каждого спина
- Используется для тестирования и демонстрации

### Атласы

- Объединение множества кадров в один файл
- Оптимизация загрузки и рендеринга
- Используется для winframe анимаций

### Spine анимации

- Анимированные элементы из Spine Editor
- Каждый спайн в своем контейнере
- Независимое управление позицией и zIndex
- Монетки и индикаторы используют Spine для анимаций

### Монетки и индикаторы

- Специальные символы-монетки (индекс 8) заменяются на Spine-анимации
- Статичная матрица позиционирования для точного размещения монеток
- Индикаторы под рилами загораются при появлении монеток на риле
- Sprite pooling для оптимизации производительности

### Отладчик

- Визуальная настройка элементов сцены
- Сохранение позиций в localStorage
- Управление zIndex для правильного порядка отрисовки

## Полезные команды

### Создание атласа

```bash
node scripts/make-atlas.js winframe_60_fps
```

### Запуск локального сервера

**Важно:** Сервер должен запускаться из корневой директории `examples/`, а не из `slots/slot_1/`!

```powershell
# Перейдите в корневую директорию проекта
cd D:\GitHub\Spine_dev\test\spine-v8\examples

# Запустите сервер
python -m http.server 8000
```

Затем откройте в браузере: `http://localhost:8000/slots/slot_1/index.html`

Подробная инструкция: **[SERVER_SETUP.md](./SERVER_SETUP.md)**
