# Архитектура каскадного слота (slot_5)

## Проблема

**CascadeManager.js** совмещает в одном месте:
- логику игры (выигрыш 7+, удаление, уплотнение колонок, досыпание);
- анимацию (таймеры, падение символов, задержки между колонками/рядами).

Из‑за таймингов и сложной асинхронной логики часто возникают баги, которые сложно воспроизвести и отладить.

## Решение

Разделить **логику** и **представление**:

1. **Сценарий-генератор (логика без анимации)**  
   Отдельный модуль с той же игровой логикой, но без PIXI, без таймеров и без анимации:
   - определение выигрыша (7+ одинаковых символов);
   - удаление выигрышных символов;
   - уплотнение по колонкам (символы «вниз», пустоты сверху);
   - досыпание: порядок — колонки 0→5, внутри колонки ряды 0→4.

   Работает пошагово (step-by-step), в процессе спинов пишет и сохраняет сценарий (JSON или JS).

2. **CascadeManager (анимация)**  
   Остаётся ответственным за отрисовку и анимацию. В режиме **реплей** получает готовые шаги сценария и только анимирует переход к следующему состоянию сетки, не вычисляя каскады сам.

## Цели

- **Один источник правды** для правил — вся логика каскада в одном месте, без гонок и таймеров.
- **Сценарий** — и тест (эталон результата), и реплей для отладки.
- **Проще искать баги**: если сценарий говорит «после спина сетка A, после каскада сетка B», а в игре получается B′ ≠ B — баг в анимации/таймингах.

## Формат сценария

- Массив шагов: `{ "event": "spin" | "cascade", "grid": number[][] }`.
- `grid` — 5 рядов × 6 колонок, по рядам: `grid[row][col]`, индексы символов 0–7.

## Что уже есть

- **ScenarioGenerator.js** — генератор сценариев (логика каскада, без анимации).
- **scenario_10_spins_2_cascades.json** — пример: 10 спинов, 2 с каскадом.
- **scenario_complex_3_cascades.json** — пример: один спин с выигрышем по полю, 3 каскада подряд.

## Дальнейшие шаги

- Вынести общую логику (подсчёт выигрыша, уплотнение, порядок досыпания) в один переиспользуемый модуль.
- Добавить в CascadeManager режим «реплей по сценарию»: подставлять целевое состояние сетки из сценария и только анимировать к нему.
- Сохранять сценарий в виде понятного кода (например, `export const SCENARIO = [...]` в .js) для тестов и реплеев.
