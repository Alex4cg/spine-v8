# Показ минивинов — логика и тайминги

## Терминология

- **Мини вин**: выплата одного кластера. Показывается над этим кластером.
- **Мини тотал**: итог каскада. Показывается по центру поля.

## Когда что показывается

### Мини вины

Показываются при любом выигрыше — по одному тексту на каждый кластер.

### Мини тотал

| Сценарий                  | Мини тотал? |
| ------------------------- | ----------- |
| 1 кластер, без бомбы      | Нет         |
| 2+ кластера, без бомбы    | Да          |
| 1/2+ кластера + бомба     | Да          |

## Позиционирование

### Мини вин — выбор ячейки

Приоритетные ячейки: **(1,1)**, **(1,3)**, **(4,1)**, **(4,3)** (col, row).

1. Если в кластере есть приоритетная ячейка — выбирается она.
2. Иначе — выбирается ячейка кластера, ближайшая к приоритетным (метрика Manhattan).

### Мини вин — центр текста

Центр текста совпадает с центром выбранной ячейки. Anchor: 0.5 (центр спрайта).

### Мини тотал — позиция

Центр матрицы 6×5. Anchor: 0.5. Множитель и результат при бомбе используют одну и ту же точку.

## Источник данных

Данные берутся из шага сценария:

| Данные              | Поле сценария             | По умолчанию               |
| ------------------- | ------------------------- | -------------------------- |
| Выплата кластера    | `payouts[i].payout`        | 0                          |
| Итог каскада        | `totalPayout`              | 0                          |
| Множитель           | `multiplier`               | 1                          |
| Результат при бомбе | `totalPayout × multiplier` | —                          |

При бомбе в бонусной игре с активным жёлтым сундуком CascadeManager передаёт в мини тотал опции отображения (`displayOpts`): база, эффективный множитель (жёлтый + бомба, напр. 25+5=30) и итог. На оверлее показывается «база×30» и результат (напр. «15.00×30», «+450.00»). Без бонуса или без жёлтого используются только данные шага (`totalPayout`, `multiplier`).

## Порядок вызова (интеграция)

[MiniWinManager.js](slots/slot_5/MiniWinManager.js) вызывается из [CascadeManager.js](slots/slot_5/CascadeManager.js) в `_handleScenarioWinCheck`:

1. **showMiniWins(step)** — при старте (сценарий 1 — полный цикл; сценарии 2 и 3 — multiClusterNoBomb).
2. Удаление символов и мини вины/тотал выполняются параллельно для **сценариев 2 и 3**.
3. Сценарий 3: `showMiniWinsAndTotalWithBomb(step, 2000)` — мини тотал стартует в t=1 с.
4. **Задержка перед досыпанием** — небольшая пауза (например 250 мс) после завершения показа мини винов/тотала, чтобы экран успел «усвоиться».
5. **clear()** — перед запуском досыпания (`processCascade`).
