# Инструкция по настройке GitHub Pages

## Шаги для публикации игры

### 1. Закоммитить и запушить изменения

Коммит с игрой «8 марта» уже создан локально. Чтобы отправить его в **Secret-santa-xoxoxo/spine-v8**:

1. В корне репозитория (`d:\GitHub\Spine_dev\test\spine-v8`) выполните push **по URL без добавления remote** (так не трогается `.git/config` и не будет ошибки блокировки):
   ```powershell
   git push https://github.com/Secret-santa-xoxoxo/spine-v8.git 2025-12-16-trij:2025-12-16-trij
   ```
   Git запросит логин/токен GitHub — введите данные учётной записи **Secret-santa-xoxoxo**. Если `git remote add` из‑за блокировки не срабатывал, этой одной команды достаточно.
2. После успешного push зайдите на GitHub: **Settings → Pages** и нажмите **Save** (ветку не меняйте). Подождите 1–2 минуты и откройте ссылку на игру.

### 2. Настроить GitHub Pages

1. Перейдите на GitHub: **https://github.com/Secret-santa-xoxoxo/spine-v8**
2. Откройте **Settings** → **Pages** (в левом меню)
3. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**
4. **Branch**: выберите **main** (или нужную ветку) и папку **/ (root)**
5. Нажмите **Save**

### 3. Дождаться публикации

GitHub Pages обычно публикует сайт в течение 1–2 минут. В разделе Pages появится сообщение:
> "Your site is live at https://secret-santa-xoxoxo.github.io/spine-v8/"

### 4. Открыть игру «8 марта»

После публикации игра будет доступна по адресу:

**https://secret-santa-xoxoxo.github.io/spine-v8/examples/slots/8_march/index.html**

## Примечания

- Файл `.nojekyll` в корне репозитория и в `examples/` нужен для корректной работы GitHub Pages (папки с подчёркиванием не скрываются Jekyll)
- Все пути к ресурсам в игре относительные и работают при публикации из корня репозитория
- Чтобы сменить ветку для GitHub Pages, измените настройки в Settings → Pages

## Почему 404 «File not found»?

Если по ссылке на игру открывается 404, значит на GitHub в той ветке, из которой собирается Pages (у вас это **2025-12-16-trij**), ещё нет папки `examples/slots/8_march/`. Часто так бывает, если коммиты с игрой не были запушены в этот репозиторий.

**Что сделать:** выполните push (шаг 1 выше) в ветку **2025-12-16-trij**, затем в Settings → Pages нажмите **Save**, подождите 1–2 минуты и обновите страницу с игрой.

## Ошибка «could not lock config file .git/config»

Если при `git remote add` появляется эта ошибка, **remote добавлять не обязательно**. Выполните push напрямую по URL (команда в шаге 1 выше). Если всё же нужен именованный remote: закройте Cursor и все программы, использующие репозиторий, удалите файл `d:\GitHub\Spine_dev\test\spine-v8\.git\config.lock` (если есть), затем снова выполните `git remote add secret-santa ...`.

## Если что-то не работает1. Убедитесь, что push выполнен в ту же ветку, что указана в Settings → Pages (2025-12-16-trij)
2. В Settings → Pages нажмите **Save**, чтобы запустить пересборку
3. Подождите несколько минут — GitHub Pages может обновляться с задержкой
4. Проверьте консоль браузера (F12) на ошибки загрузки ресурсов
