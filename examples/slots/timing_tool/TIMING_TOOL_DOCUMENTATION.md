# Timing Tool — Документация

## Назначение

Инструмент для настройки изинга анимации **падения символа с баунсом** (отскоком).  
Позволяет визуально редактировать кривые Безье и сразу видеть результат на превью.

---

## Структура анимации

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│ WAIT    │ → │ START   │ → │ LINEAR  │ → │ END     │ → │WAIT_END │ → repeat
│ 0.5s    │   │ easing  │   │ motion  │   │ easing  │   │ 0.5s    │
└─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘
```

| Фаза | Описание |
|------|----------|
| **WAIT** | Пауза перед началом (0.5 сек) |
| **START** | Изинг старта — кривая Безье (отскок вверх перед падением) |
| **LINEAR** | Линейное падение с постоянной скоростью |
| **END** | Изинг торможения — кривая Безье (приземление с баунсом) |
| **WAIT_END** | Пауза после остановки (0.5 сек) |

---

## Три контейнера

### 1. Start (голубой)
- **Ширина** = длительность в миллисекундах (default: 500ms)
- **Высота** = диапазон значений ±50px (от -50 до +50)
- **Кривая Безье** — настраиваемая форма старта
- Первая точка фиксирована (START), последняя двигается по Y

### 2. Linear (зелёный)
- **Ширина** = длительность в миллисекундах (default: 500ms)
- **Высота** = дистанция падения в пикселях (default: 100px)
- **Диагональ** — показывает скорость (угол наклона)
- Чем круче диагональ — тем быстрее падение

### 3. End (оранжевый)
- **Ширина** = длительность в миллисекундах (default: 500ms)
- **Высота** = диапазон значений ±50px (от -50 до +50)
- **Кривая Безье** — настраиваемая форма торможения
- Последняя точка фиксирована (END), первая двигается по Y

---

## Система координат

```
     -50px ─────────────────── верх контейнера (отскок вверх)
       │
       0 ─────────────────── середина (нет смещения)
       │
     +50px ─────────────────── низ контейнера (падение вниз)
```

- **Ось X**: время в миллисекундах
- **Ось Y**: смещение в пикселях
- **Положительное значение** = движение вниз (падение)
- **Отрицательное значение** = движение вверх (отскок)

---

## Формула итоговой позиции

```javascript
totalY = Start.value + Linear.distance + End.value
```

Пример:
- Start curve ends at **-20px** (подпрыгнул)
- Linear distance **100px** (падение)
- End curve ends at **+10px** (небольшой баунс вниз)
- **Итого: -20 + 100 + 10 = 90px** вниз от начальной позиции

## Управление

### Перетаскивание
- **Контейнер** — перемещается по холсту (клик внутри и тянуть)
- **Ключевые точки** — двигаются по Y (значение в px)
- **Штанги Безье** — управляют формой кривой

### Ресайз
- **Правый хендл** (справа от контейнера) — изменяет ширину (длительность ms)
- **Нижний хендл** (под контейнером) — изменяет высоту (диапазон px)

### Ограничения
| Элемент | Ограничение |
|---------|-------------|
| START точка | t=0 фиксирован, Y двигается |
| END точка | t=1 фиксирован, Y двигается |
| Промежуточные точки | Свободное перемещение |

### Подгонка тангенса к Linear

Чтобы переход из кривой в линейную фазу (и обратно) был без излома, касательная в точке стыка должна совпадать с направлением линейного движения.

| Кнопка | Действие |
|--------|----------|
| **fit start** | Подгоняет **выход** кривой Start к Linear: выставляет `inHandle` последнего ключа Start так, чтобы касательная в конце кривой совпадала с наклоном линейной фазы. |
| **fit end** | Подгоняет **вход** кривой End к Linear: выставляет `outHandle` первого ключа End так, чтобы касательная в начале кривой совпадала с наклоном линейной фазы. |

**Формула наклона** (в координатах контейнера: нормированное время t, значение в px):

```
slope = (linear.h × container.w) / linear.w
```

- Для Start: `container.w = start.w` (длительность Start в ms).
- Для End: `container.w = end.w` (длительность End в ms).

Тангенс задаётся парой `(dx, dy)` с соотношением `dy/dx = slope`. Длину вектора задаёт ползунок.

### Ползунок «Длина тангенса»

- Расположен под кнопками **fit start** и **fit end**.
- Диапазон: **0.05 … 0.5** (по умолчанию 0.2).
- Задаёт длину подстраиваемого тангенса: `dx` берётся из ползунка, `dy = dx × slope`.
- Чем больше значение — тем длиннее ручка Безье и плавнее переход; меньше — более короткий тангенс у стыка.

### Кнопка «1 шаг»

Нормализует **линейный сегмент** до одного шага **пропорционально**, не меняя скорость (px/ms):

| Что делается | Формула |
|--------------|---------|
| Текущая скорость | `speed = linear.h / linear.w` (px/ms) |
| Новое перемещение | `newH = step` (или 100 px, если «Шаг (px)» = 0) |
| Новая длительность | `newW = newH / speed` (чтобы скорость осталась той же) |

Итог: график линейного сегмента сокращается до одного шага по вертикали и пропорционально по времени; наклон (скорость) не меняется. Минимумы: высота ≥ 10 px, ширина ≥ 10 ms.

### Сохранение и загрузка

**Правило:** все изменяемые параметры редактора сохраняются и загружаются. Любой настраиваемый пользователем параметр должен входить в сохраняемый JSON и восстанавливаться при загрузке (и при применении экспортированного JSON).

В браузере доступны **выпадающий список** и две кнопки. Список файлов задаётся статическим манифестом `save_load/list.json` (массив имён JSON-файлов). При добавлении новых JSON в папку `save_load/` нужно дописать имя в этот манифест.

| Элемент | Назначение |
|---------|------------|
| **Загрузить из** | Выпадающий список: пункты берутся из `save_load/list.json` (только строки с суффиксом `.json`). При открытии страницы и по кнопке «Загрузить» список обновляется. При смене пункта выбранный файл сразу загружается и применяется. |
| **Загрузить** | Обновляет список из `list.json`, затем загружает выбранный файл (fetch `save_load/<имя>`) и применяет состояние: контейнеры, кривые, шаг, длина тангенса, матрица (колонки×строки), задержка старта (мс), длина ленты и прочие изменяемые параметры. |
| **Сохранить** | Скачивает текущее состояние в JSON-файл; имя файла берётся из выбранного пункта списка (например `default.json`). Запись «в путь» в браузере недоступна — только загрузка по URL и скачивание. |

Формат сохраняемого/загружаемого JSON совпадает с экспортом (см. раздел «Экспорт JSON»), плюс поля `tangentLength`, `startCurve`, `endCurve`, `playfieldCols`, `playfieldRows`, `reelStartDelayMs`, `tapeLength`, `extraLength`, `previewMode`, `previewSymbolStyle` и т.д. для полного восстановления редактора.

### Шаг символа (Step) и снаппинг

Параметр **«Шаг (px)»** в тулбаре задаёт размер одного символа в пикселях. Используется для **дискретных остановок** ленты (как в механическом слоте): все ключевые смещения привязываются к сетке `k·step`, поэтому итоговая позиция после цикла всегда кратна шагу.

| Значение | Поведение |
|----------|-----------|
| **0** | Снаппинг отключён — значения в px произвольные |
| **> 0** (например 100) | Снаппинг включён — значения округляются к ближайшему кратному step |

**Что именно снаппится к шагу:**

| Элемент | Что снаппится | Когда |
|---------|----------------|-------|
| **Start** | Значение **последнего** ключа (выход из изинга) | При перетаскивании этой ключевой точки |
| **Linear** | Высота контейнера (`distancePx`) | При ресайзе нижним хендлом (только 0, step, 2·step, …) |
| **End** | Значение **первого** ключа (вход с Linear) и **последнего** ключа (финальная позиция) | При перетаскивании первой или последней ключевой точки |

**Формула снаппинга:** `snapToStep(v, step) = step > 0 ? round(v / step) * step : v`.

**Итог:** если выход Start, высота Linear и вход/выход End кратны step, то **суммарное смещение за цикл** тоже кратно step → конечная координата ленты дискретна (0, ±step, ±2·step, …). Ленту можно считать бесконечной: сдвиг на N·step визуально эквивалентен сдвигу на 0 (повтор паттерна).

## Превью кубиков и режим лент

**При шаге = 0 (без снаппинга):** 5 цветных кубиков (10×10px) демонстрируют результат настройки:

1. Стоят 0.5 сек (WAIT)
2. Выполняют Start easing
3. Падают линейно (Linear)
4. Выполняют End easing
5. Стоят 0.5 сек (WAIT_END)
6. Повторяют 2 цикла, затем рестарт

**При шаге > 0:** вместо кубиков отображаются **вертикальные ленты** (режим «reels»): полосы из прямоугольников высотой `step` px. Количество колонок и строк задаётся полями **Матрица** (по умолчанию 3×3). Смещение по вертикали = `progress % (N·step)` (N = число символов в пуле), что даёт эффект бесконечной прокрутки. Остановка после цикла совпадает с границей символа («в яблочко»).

**Один спин — одно общее событие.** Превью считает спин единым циклом: первая колонка стартует в момент 0, каждая следующая — с задержкой (Задержка старта), у каждой колонки своя длина линейной части (Длина ленты + колонка × Доп длина). Длительность одного спина = задержка до старта последней колонки + полное время прогона последней колонки (WAIT → Start → Linear → End → WAIT_END). Все ленты синхронизированы с этим общим циклом: по его окончании начинается следующий спин.

### Режим превью: Стандарт и Hold & Win

На панели (блок Матрица/Превью) переключатель **«Стандарт»** / **«Hold & Win»** выбирает вид превью. Режим сохраняется в JSON (`previewMode`) при сохранении и восстанавливается при загрузке.

| Режим | Модуль | Описание |
|-------|--------|----------|
| **Стандарт** | `timing_preview.js` | Вертикальные колонки лент, общая фрейм-маска на всё поле. Задержка старта по колонкам: колонка `col` стартует через `col × задержка` мс (слева направо). |
| **Hold & Win** | `timing_preview_hold_win.js` | Сетка ячеек N×M (матрица). У каждой ячейки своя фрейм-маска размером в **один прямоугольник** (высота = шаг символа). Каждая ячейка — одна лента; задержки слева направо, сверху вниз: индекс рила `reelIndex = row × cols + col`, старт через `reelIndex × задержка` мс. |

Кривые и параметры (шаг, матрица, задержка, длина ленты, доп. длина) общие; меняется только способ отрисовки и порядок нумерации рилов.

### Переключатель «Прямоугольники» / «Текстуры»

В блоке **PREVIEW** переключатель **«Прямоугольники»** / **«Текстуры»** задаёт, чем заполняются ячейки лент в превью (при шаге > 0):

| Режим | Описание |
|-------|----------|
| **Прямоугольники** | Цветные прямоугольники по индексу символа (как раньше): `fillRect` + `strokeRect`, цвет по hue. |
| **Текстуры** | Вместо заливки рисуются изображения из папки `sim/` в **натуральном размере**. Текстура выравнивается **центр по центру** с ячейкой (без масштабирования). |

**Папка текстур:** изображения загружаются из `slots/timing_tool/sim/`. Конвенция имён:
- Либо манифест `sim/list.json` — массив имён файлов (например `["0.png", "1.png", …]`).
- Либо файлы по умолчанию: `0.png`, `1.png`, … `15.png`.

Если текстур нет или загрузка не удалась, в режиме «Текстуры» превью отображает те же прямоугольники, что и в режиме «Прямоугольники». Режим сохраняется в JSON в поле `previewSymbolStyle` (`'rectangles'` или `'textures'`) и восстанавливается при загрузке.

### Задержка старта колонок

Поле **«Задержка старта (мс)»** в тулбаре задаёт сдвиг старта анимации между колонками. Используется для каскадного запуска лент (как в слотах: первая колонка трогается сразу, вторая — с задержкой, третья — с удвоенной задержкой и т.д.).

| Параметр | Описание |
|----------|----------|
| **Значение (мс)** | Задержка между соседними колонками в миллисекундах. Для колонки с индексом `col` эффективный старт = `col × задержка` мс. |
| **0** | Все колонки стартуют одновременно. |
| **> 0** (например 150) | Колонка 0 — сразу, колонка 1 — через 150 мс, колонка 2 — через 300 мс и т.д. |

Задержка читается из UI при каждой отрисовке превью (через API `getReelStartDelayMs`), поэтому не сбрасывается при смене кривых или перерисовке. В подписи превью при задержке > 0 отображается `delay=…ms`. Значение по умолчанию в поле — 150 мс.

### Доп длина (по колонкам)

Поле **«Доп длина»** в блоке Матрица задаёт, на сколько **линейных отрезков (шагов)** больше проходит каждая следующая колонка. Влияет и на длину, и на время линейной фазы: вклинивается в линейную часть аналогично параметру «Длина ленты».

| Параметр | Описание |
|----------|----------|
| **Значение** | Число дополнительных отрезков на каждую следующую колонку. Для колонки с индексом `col` (0-based): число отрезков = **Длина ленты** + `col × Доп длина`. |
| **0** | Все колонки проходят одинаковое число отрезков (только «Длина ленты»). |
| **1** | Колонка 0 — N отрезков, колонка 1 — N+1, колонка 2 — N+2 и т.д.; каждая следующая на 1 шаг дальше и дольше по времени. |

Формулы для колонки `col`: дистанция Linear = `(Длина ленты + col × Доп длина) × linear.h` (px), длительность Linear = `(Длина ленты + col × Доп длина) × linear.w` (ms). В превью лент каждая колонка анимируется со своей длительностью и дистанцией линейной части. Параметр сохраняется и загружается (правило: все изменяемые параметры сохраняются и загружаются).

## Экспорт JSON

Кнопка **"Скопировать JSON"** выдаёт:

```json
{
  "step": 0,
  "tapeLength": 3,
  "extraLength": 0,
  "containers": {
    "start": {
      "x": 200, "y": 300,
      "durationMs": 500,
      "rangePx": 100,
      "actualDistancePx": -20
    },
    "linear": {
      "x": 750, "y": 300,
      "durationMs": 500,
      "distancePx": 100
    },
    "end": {
      "x": 1300, "y": 300,
      "durationMs": 500,
      "rangePx": 100,
      "actualDistancePx": 10
    }
  },
  "totals": {
    "durationMs": 1500,
    "distancePx": 90
  },
  "startCurve": [
    { "t": 0, "value": 0, "in": {...}, "out": {...} },
    { "t": 1, "value": -20, "in": {...}, "out": {...} }
  ],
  "endCurve": [
    { "t": 0, "value": 0, "in": {...}, "out": {...} },
    { "t": 1, "value": 10, "in": {...}, "out": {...} }
  ]
}
```

- **`step`** — текущее значение «Шаг (px)» (0 = без снаппинга). Игра может использовать его для отрисовки ленты: полоса символов высотой `step` каждый, позиция = value кривой, отрисовка со сдвигом по модулю `(N·step)` для бесшовного повтора.

## Экспорт для игрового движка

Кнопки **EXPORT_PRESET** и **EXPORT_PACK** отдают JSON **только с полями, нужными игровому движку** для идентичной анимации лент. Поля, используемые только в редакторе (позиции блоков на холсте, длина тангенса, режим превью и т.п.), в этот экспорт не входят.

### Параметры для движка

| Параметр | Тип | Назначение в движке |
|----------|-----|---------------------|
| **step** | number | Размер символа в px; 0 = без снаппинга. Нужен для дискретных остановок и отрисовки ленты (высота одного символа, сдвиг по модулю N·step). |
| **tapeLength** | number | Базовое число линейных отрезков (шагов) на одну колонку. |
| **extraLength** | number | Доп. отрезков на каждую следующую колонку: колонка `col` имеет `tapeLength + col * extraLength` отрезков. |
| **reelStartDelayMs** | number | Задержка старта между колонками (мс). Колонка `col` стартует через `col * reelStartDelayMs`. |
| **containers.start** | object | Только **durationMs**, **rangePx** (высота диапазона в px). Позиция x,y — только для холста редактора. |
| **containers.linear** | object | Только **durationMs** (длительность одного отрезка, мс), **distancePx** (дистанция одного отрезка, px). Итог для колонки col: длительность = (tapeLength + col×extraLength)×durationMs, дистанция = (tapeLength + col×extraLength)×distancePx. |
| **containers.end** | object | Только **durationMs**, **rangePx**. |
| **startCurve** | array | Кривая Безье старта: массив `{ t, value, in: { dx, dy }, out: { dx, dy } }`. t — нормированное время 0…1, value — смещение в px. Движок интерполирует по этой кривой за время containers.start.durationMs. |
| **endCurve** | array | Кривая Безье торможения; тот же формат. Интерполяция за containers.end.durationMs. |

Опционально в экспорт могут входить **playfieldCols**, **playfieldRows** — размер сетки рилов (если движок берёт его из этого JSON).

### Минимальная структура экспортируемого JSON

```json
{
  "step": 40,
  "tapeLength": 3,
  "extraLength": 0,
  "reelStartDelayMs": 150,
  "containers": {
    "start": { "durationMs": 500, "rangePx": 100 },
    "linear": { "durationMs": 500, "distancePx": 100 },
    "end": { "durationMs": 500, "rangePx": 100 }
  },
  "startCurve": [
    { "t": 0, "value": 0, "in": { "dx": 0.2, "dy": 0 }, "out": { "dx": 0.2, "dy": 0 } },
    { "t": 1, "value": -20, "in": { "dx": -0.15, "dy": -30 }, "out": { "dx": 0, "dy": 0 } }
  ],
  "endCurve": [
    { "t": 0, "value": 0, "in": { "dx": 0, "dy": 0 }, "out": { "dx": 0.2, "dy": 25 } },
    { "t": 1, "value": 10 }
  ]
}
```

- **EXPORT_PRESET** — активна только при выбранном пресете; скачивает один файл `timing_preset_<id>.json` с описанным выше форматом для текущего пресета.
- **EXPORT_PACK** — активна только когда все 6 слотов пакета заполнены; скачивает один файл `reel_animation.json` с ключами `regNorm`, `regFast`, `regFfast`, `bonNorm`, `bonFast`, `bonFfast`, каждый элемент — объект того же формата (только поля для движка).

## Ключевые функции (API)

| Функция | Возвращает | Описание |
|---------|------------|----------|
| `getStartDuration()` | ms | Длительность Start фазы |
| `getLinearDuration(col)` | ms | Длительность Linear фазы; опциональный `col` — индекс колонки (для «Доп длина»). Без аргумента = колонка 0. |
| `getEndDuration()` | ms | Длительность End фазы |
| `getStartDistance()` | px | Смещение Start кривой (last - first) |
| `getLinearDistance(col)` | px | Расстояние линейного падения для колонки `col` (опционально); без аргумента = колонка 0. |
| `getEndDistance()` | px | Смещение End кривой (last - first) |
| `getTotalDistance(col)` | px | Start + Linear + End; опциональный `col` для учёта «Доп длина». |
| `evaluateStartBezier(t)` | px | Значение Start кривой в точке t |
| `evaluateEndBezier(t)` | px | Значение End кривой в точке t |
| `getCubeProgress(elapsed, col)` | px | Полная позиция по времени; опциональный `col` — для превью лент с разной длиной по колонкам. |
| `fitStartTangentToLinear()` | — | Подгоняет касательную при выходе из Start (inHandle последнего ключа) под наклон Linear |
| `fitEndTangentToLinear()` | — | Подгоняет касательную при входе в End (outHandle первого ключа) под наклон Linear |
| `getTangentLength()` | 0.05…0.5 | Текущая длина тангенса из ползунка (используется при fit start/end) |
| `getSymbolStep()` | number | Текущий шаг символа в px (0 = без снаппинга) |
| `snapToStep(value, step)` | number | Округляет value к ближайшему кратному step; при step ≤ 0 возвращает value без изменений |
| `getSaveState()` | object | Полное состояние редактора: containers, startCurve, endCurve, step, tangentLength, playfieldCols, playfieldRows, reelStartDelayMs, tapeLength, extraLength и все прочие изменяемые параметры (для Сохранить/Загрузить). |
| `applyImportedJson(obj)` | — | Применяет загруженный JSON: восстанавливает все изменяемые параметры (контейнеры, кривые, шаг, длину тангенса, матрицу, задержку старта, длину ленты, доп длину и т.д.). |

**Нормализация «1 шаг»:** при нажатии кнопки линейный контейнер меняется так: `linear.h = step` (или 100), `linear.w = step / (linear.h_old / linear.w_old)` — скорость (px/ms) сохраняется.

## Применение в игре

Экспортированный JSON можно использовать для:

1. **Symbol Drop Animation** — падение символов на барабанах слота
2. **Bounce Effect** — эффект приземления с отскоком
3. **Custom Easing** — любые анимации с настраиваемым изингом

### Пример использования:

```javascript
// Загрузка конфига
const timing = JSON.parse(jsonFromTool);

// Применение к символу
function animateSymbol(symbol, elapsed) {
  const totalDuration = timing.totals.durationMs;
  const progress = elapsed / totalDuration;
  
  // Вычисление позиции по фазам...
  symbol.y = baseY + calculatePosition(progress, timing);
}
```

## Краткая сводка

| Область | Что есть |
|---------|----------|
| **Фазы** | Start (easing) → Linear (постоянная скорость) → End (easing) |
| **Контейнеры** | Ширина = длительность (ms), высота = смещение/диапазон (px). Linear: высота = дистанция за фазу. |
| **Скорость Linear** | px/ms = `linear.h / linear.w`; угол наклона на графике = скорость. |
| **Шаг (step)** | Размер символа в px; снаппинг ключей и высоты Linear к сетке step. При step > 0 превью — ленты (матрица колонок×строк). По умолчанию 40 px. |
| **Задержка старта (мс)** | Сдвиг старта анимации между колонками: колонка `col` стартует через `col × задержка` мс. По умолчанию 150 мс. |
| **Доп длина** | Каждая следующая колонка проходится на N шагов больше (N = значение): колонка `col` — «Длина ленты» + `col × Доп длина` отрезков; влияет на длину и время Linear. По умолчанию 0. |
| **1 шаг** | Кнопка: Linear сокращается до одного шага по вертикали, длительность пересчитывается так, чтобы скорость не изменилась. |
| **Сохранение** | Выпадающий список «Загрузить из»: пункты из `save_load/list.json`; при выборе — загрузка выбранного файла; при сохранении имя файла берётся из выбранного пункта (скачивание). В состояние входит `previewMode` (standard / holdAndWin). |
| **Превью** | Тоггл «Стандарт» / «Hold & Win»; тоггл «Прямоугольники» / «Текстуры» (изображения из `sim/` в натуральном размере, центр по центру с ячейкой); режимы сохраняются и загружаются (`previewMode`, `previewSymbolStyle`). |
